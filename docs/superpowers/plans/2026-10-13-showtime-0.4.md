# showTime 0.4.0 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: superpowers:executing-plans (inline). Steps use `- [ ]`.

**Goal:** Ship 0.4.0: narration (`show.say`, four TTS engines), holds that wait for the voice,
music with ducking, click/keystroke sounds, subtitles (SRT and burned in); 9:16 and 1:1 cuts with a
follow camera; GIF and WebP output.

**Architecture:** Same layers. New pure modules: `src/timeline/narration.ts` (windows, holds,
subtitle cues, SRT, sound events), `src/audio/mix.ts`, `src/audio/sfx.ts`. New I/O modules:
`src/audio/tts.ts`, `src/audio/wav.ts`, `src/audio/decode.ts`, `src/convert.ts`. The renderer's
public folder becomes `.showtime/<name>/`.

**Tech Stack:** unchanged (Playwright 1.64, Remotion 4.0.535, zod 4, commander 14, vitest 4,
ffmpeg on PATH).

**Spec:** `docs/superpowers/specs/2026-10-13-showtime-0.4-design.md`

## Global Constraints

- `src/timeline/**` and `src/audio/mix.ts`, `src/audio/sfx.ts` stay pure: no `node:` imports.
- Functions passed to `page.evaluate` / init scripts: no inner named functions (tsx `__name`).
- Schema changes end with `npm run schema:write` (the drift test enforces it).
- Every user-visible error starts with what failed and says what to do.
- Node ≥ 20; no new runtime dependencies. Shell commands never get narration text in argv or in
  the command string: `system` passes a file, `command` passes stdin.
- 0.3 takes keep rendering (no re-record): `keys` optional, `video.file` unchanged on disk.

## Review Focus

1. A narrated last step: the hold sits before the outro, and the mix covers intro + video + outro.
2. `say` text with quotes, newlines, a leading dash or Cyrillic reaches every engine intact, and
   never reaches a shell command line.
3. A music file shorter than the video loops; a longer one is cut; mono or 44.1 kHz input is
   resampled to stereo 48 kHz.
4. A 0.3 take (no `keys`) renders with `sounds: true`: ticks spread over each `type` step.
5. 9:16 with a portrait (mobile) viewport: the content covers the window, and the focus clamp never
   shows past the content's edges.

**Produces:** `Show.say?: string`; `Script.audio: { voice: Voice; music?: { file; volume };
sounds: boolean; subtitles: 'off'|'file'|'burn' }`; `Voice = { engine; name?; speed; model?;
instructions?; command? }`; `audio.music.file` absolute after load; brand file `audio`.

- [ ] Tests (RED): defaults (`engine 'system'`, `speed 1`, `sounds false`, `subtitles 'file'`,

- [ ] Tests (RED): a line longer than its window adds a hold of the difference + gap just before the

`clickSamples(rate)`, `keySamples(rate, variant)`; `mixTrack(plan): Float32Array[]`;
`musicGain(tMs, voices, totalMs)`; `decodeAudio(file, opts): Promise<Float32Array[]>`;
`voiceKey(voice, text)`; `synthesize(voice, text, out)`; `ensureVoices(loaded): Promise<Record<where, { file; durationMs }>>`;

- [ ] Tests (RED): WAV round trip; click/key are short, non-silent, under full scale; mixer places a

  the status; missing key → error naming the variable; cache hit does not call the engine.
  Integration: render with narration has an audio stream, is longer by the holds, writes the SRT;
