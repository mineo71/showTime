# showTime 0.3.0 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: superpowers:executing-plans (inline). Steps use `- [ ]`.

**Goal:** Ship 0.3.0: contact sheet, `lint`, `--json` everywhere; hooks, mocks, frozen clock,
dialogs, safe re-take, SSE-aware settle, relative `goto`; caption trimming and placement, outro
card, logo, brand file.

**Architecture:** Same layers as the MVP. New pure modules: `src/lint.ts`, projection in
`src/timeline/layout.ts`. New I/O modules: `src/runner/hooks.ts`, `src/sheet.ts`,
`src/script/config.ts`. The timeline contract grows (`outro`, `logo`, `Caption.position`).

**Tech Stack:** unchanged (Playwright 1.64, Remotion 4.0.535, zod 4, commander 14, vitest 4).

**Spec:** `docs/superpowers/specs/2026-10-13-showtime-0.3-design.md`

## Global Constraints

- `src/timeline/**` stays pure: no `node:` imports, extensionless imports.
- Functions passed to `page.evaluate` / init scripts: no inner named functions (tsx `__name`).
- Schema changes end with `npm run schema:write` (the drift test enforces it).
- Every user-visible error starts with what failed and says what to do.
- Node ≥ 20; no new runtime dependencies.

## Review Focus

1. A `before` hook that hangs or prints megabytes: the 120 s timeout fires and the error keeps only
   the output tail.
2. `app.mock` with `delayMs` on a route the page aborts (navigation away mid-request): no unhandled
   rejection.
3. A failed re-take when no previous take exists: `take.tmp` is left for debugging, no crash.
4. `meta.logo` in both the brand file and the script: the script's path wins and resolves against
   the script's folder.
5. Captions on a step whose target sits under the caption only after zooming: placement uses the
   camera at start, middle and end.

### Task 1: Script format and brand file

**Files:** `src/script/schema.ts`, `src/script/config.ts` (new), `src/script/load.ts`,
`src/script/hash.ts`; tests `test/unit/schema.test.ts`, `test/unit/load.test.ts`, `test/unit/hash.test.ts`.

**Produces:** `Script.hooks: { before: Hook[]; after: Hook[] }`,
`Hook = { run: string } | { request: { url; method; json?; headers? } }`;
`Script.app.mock: Mock[]` (`{ url, method?, status, json?, body?, headers?, delayMs? }`),
`app.clock?: string`, `app.dialogs: 'accept' | 'dismiss'`;
`Script.meta.logo?: string` (absolute after load), `meta.outro?: { title; subtitle?; url? }`;
`LoadedScript.config: string | null`; `findConfig(dir): string | null`.

- [ ] Tests (RED):
  - schema accepts hooks/mock/clock/dialogs/outro/logo; defaults `hooks {before:[],after:[]}`,
    `mock []`, `dialogs 'accept'`, mock `status 200`, request `method 'POST'`.
  - rejects `app.clock: 'yesterday'` (path `app.clock`), a hook `{ shell }` (path `hooks.before.0`),
    a mock with both `json` and `body`.
  - hash: hooks do not change `actionHash`; `app.mock` does.
  - load: nearest `showtime.config.json` upward applies `style`/`meta` as defaults, script wins
    per key, `meta.logo` from config resolves against the config folder, `loaded.config` is its path;
    script `meta.logo` resolves against the script folder; a missing logo file fails with
    `meta.logo not found`; unknown config keys fail naming the config file; no config → `null`.
- [ ] Implement: schema fields; `config.ts` (`findConfig`, `ConfigSchema` strict
  `{ $schema?, style?: object, meta?: object }`, validated by parsing the merged script); merge raw
  JSON before `parseScript`; resolve logo paths before merging.
- [ ] `npm test` green; `npm run schema:write`; commit `feat(script): hooks, mocks, clock, dialogs, outro, logo, brand file`.
