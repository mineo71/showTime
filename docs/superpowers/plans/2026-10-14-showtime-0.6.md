# showTime 0.6.0 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: superpowers:executing-plans (inline). Steps use `- [ ]`.

**Goal:** Ship 0.6.0: app.hide, app.reducedMotion, wait.timeoutMs, server lifecycle, captions
that last long enough to read, a band for burned subtitles, audio.clips, --scenes and --fps,
`showtime inspect`, `check --until`.

**Architecture:** Same layers. New I/O module `src/runner/server.ts` (server lifecycle) and
`src/inspect.ts`; pure helpers in `src/timeline/{build,layout,frames}.ts` and `src/inspect.ts`
(snapshot parsing).

**Tech Stack:** unchanged.

**Spec:** `docs/superpowers/specs/2026-10-14-showtime-0.6-design.md`

## Global Constraints

- `src/timeline/**`, `src/audio/mix.ts`, `src/audio/sfx.ts` stay pure.
- 0.5 scripts and takes keep working: new `app` fields at their defaults leave the action hash
  unchanged; `server` and `audio.clips` are not part of it.
- Every user-visible error starts with what failed and says what to do.
- Functions passed to `page.evaluate` / init scripts: built as strings or without inner named functions.

## Review Focus

1. A `server` whose command exits immediately, never answers, or leaves children behind: a clear
   error, and no process left running after `check`/`record` ends (also on failure).
2. A running dev server on the URL already: reused, never killed.
3. `--scenes` with one scene, the first scene, the last scene, an unknown id; the SRT and the audio
   stay in sync with the cut.
4. A caption whose step is sped up 8×: still on screen for its reading time in output time.
5. `app.hide` with a selector that matches nothing or is invalid; `inspect` on a page with
   duplicate button names and names containing quotes.

### Task 1: Script format

**Files:** `src/script/{schema,config,load,hash}.ts`; tests `test/unit/{schema,load,hash}.test.ts`.

- [ ] Tests (RED): defaults (`hide []`, no `reducedMotion`, no `server`, `clips []`); `server.run`
  required, `timeoutMs` 1–600 s; `wait.timeoutMs` 1000–300000; clip `at` must match `scene#n`,
  `offsetMs ≥ 0`, `volume 0–1` (default 1); clip files resolve against the script folder / brand
  folder and must exist; `hide`, `reducedMotion`, `timeoutMs` change the hash only when set;
  `server` and `clips` never do; the 0.2 golden hash still holds.
- [ ] Implement; `npm run schema:write`. Commit `feat(script): hide, reducedMotion, server, clips, wait timeout`.

### Task 2: Runner

**Files:** `src/runner/{browser,steps,check,record,server}.ts`, `src/studio/server.ts`; tests
`test/unit/server-options.test.ts`, `test/integration/{reliability,server}.test.ts`.

**Produces:** `withServer(script, cwd, work)`; `CheckOptions.until?`.

- [ ] Tests (RED): an `app.hide` element has `visibility: hidden` in the take page; reduced motion
  reaches `matchMedia`; `wait` with `timeoutMs` outlasts 15 s; `check --until` stops after that
  step; `server` starts a node HTTP server, the take records it, and the process is gone afterwards;
  an already-running server is reused and survives; a command that exits fails with its output; a
  server that never answers times out.
- [ ] Implement. Commit `feat(runner): hide, reduced motion, wait timeout, check --until, server lifecycle`.

### Task 3: Timeline

**Files:** `src/timeline/{build,layout,frames,types}.ts`, `src/render/remotion/*`; tests
`test/unit/{build,layout,frames}.test.ts`.

**Produces:** caption reading time; `viewLayout(…, reserveBottom)`; `Timeline.subtitleBand`;
`Timeline.clips`; `sceneRange(timeline, steps, scenes): { from, to }`.

- [ ] Tests (RED): a 2-word caption on a step sped up 8× lasts ≥ 1.5 s of output; a following

- [ ] Implement; renderer draws subtitles in the band. Commit `feat(timeline): readable captions, subtitle band, clips, scene ranges`.
