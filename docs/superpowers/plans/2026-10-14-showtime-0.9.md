# showTime 0.9.0 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Integration tests in CI, new actions (double/right/modifier clicks, drag, upload, tabs, keys on screen), and twelve backlog fixes.

**Architecture:** CI calls one reusable workflow from the release. New steps extend `StepSchema` and `perform()` in `src/runner/steps.ts`; tab following lives in a new `src/runner/tabs.ts` used by the session, the step context and the capture. Keycaps and drag presses are new timeline arrays drawn by Remotion overlays.

**Tech Stack:** TypeScript, zod 4, Playwright, Remotion 4, vitest, GitHub Actions.

**Spec:** `docs/superpowers/specs/2026-10-14-showtime-0.9-design.md`

## Global Constraints

- Node ≥ 20; no new runtime dependencies.
- Takes recorded before 0.9 stay valid: new optional fields must not change `actionHash` of existing scripts.
- Commits carry no `Co-Authored-By` or `Claude-Session` trailers.
- Unit tests: `npm test`; integration: `npm run test:int` (≈12 min, run in the background, may be split in halves).
- Functions passed to Playwright `evaluate`/`addInitScript` must not contain inner named functions (tsx injects `__name`).

## Review Focus

1. A popup that closes itself while its step is still acting (OAuth "Allow" closes the window): the step must not fail and the main page must come back.
2. A drag whose `to` sits under a sticky header or partly off screen: a clear error, not a silent drop at the wrong place.
3. `upload` on a target that opens no chooser: the error must arrive within the step timeout, not hang.
4. Keycaps and captions at once in 9:16 and with burned subtitles: keycaps must not cover either.
5. Ctrl+C during a `before` hook: the hook's whole process group dies and showTime exits 130.

### Task 5: Tabs and popups (spec §2 tabs)

**Files:** create `src/runner/tabs.ts`; modify `src/runner/{browser,steps,check,record,capture}.ts`, `test/integration/actions.test.ts` (popup cases), `test/integration/record.test.ts` (frames of the popup).

**Interfaces:**
- Produces: `class Tabs { constructor(context, first: Page); get active(): Page; settle(): Promise<Page | null>; close(): Promise<Page> }` — `settle` follows the newest page opened since the last call (waits for its `load`, max 15 s), drops closed pages, brings the active one to front and returns it when it changed.
- Produces: `Session.tabs: Tabs`; `Session.page` getter = `tabs.active`; `trackNetwork(context: BrowserContext)`; dialogs answered via `context.on('dialog')`.
- Produces: `StepContext.tabs?: Tabs`, `StepContext.onPage?: (page: Page) => Promise<void>`; `Capture.follow(page): Promise<void>`.

Tests:
- check: click `#open-popup` (window.open) then `click #in-popup` in the popup, then `closeTab`, then a step on the main page passes; screenshots of the popup steps show the popup.
- check: `#oauth` opens a popup whose "Allow" button closes it and posts a message; the next step on the main page sees `#status` = "allowed".
- check: `closeTab` with one page → error "no other tab".
- record: the take's frames include the popup (sample a frame between the popup steps' times: its colour is the popup's background).
