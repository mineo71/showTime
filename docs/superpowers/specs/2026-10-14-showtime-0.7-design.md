# showTime 0.7.0: design — look and sound

Status: approved for implementation. The user asked for "different click sounds, different
highlight colours, TTS, click animations, a watermark and different fonts for the overlay text"
as a separate piece of work. Network replay, locales and timeline dragging follow in 0.8.0.
Builds on [0.6.0](2026-10-14-showtime-0.6-design.md).

## 1. Sound packs

`audio.sounds` takes, besides `true`/`false`:

- a pack name: `"soft"` (the 0.4 sounds; what `true` means), `"mechanical"` (a keyboard clack and
  a firm mouse click), `"pop"` (a round, bubbly pop), `"tap"` (a short, muted tick) or
  `"typewriter"` (a heavy clack and a carriage thunk);
- an object `{ "pack": "pop", "click": "sfx/click.wav", "key": "sfx/key.wav", "volume": 0.6 }`: a
  pack, your own files for clicks or keys (relative to the file that names them, must exist), and
  a volume (0–1, default 1).

All packs are synthesized in code (no audio files ship). `true` stays `soft`, so 0.4–0.6 videos
sound the same.

## 2. Highlights

- `show.highlight`: a CSS colour for this step's click animation and spotlight (default
  `style.accent`).
- `show.spotlight`: `true`/`"dim"` (the 0.3 look: everything else dims, the target gets a ring),
  `"ring"` (a ring, nothing dims) or `"glow"` (a soft coloured glow around the target, nothing dims).
- `style.spotlightDim`: how dark `dim` makes the rest (0–1, default 0.55).

## 3. Click animations

`style.click` (default `"ripple"`) and per step `show.click`:

| value | look |
|---|---|
| `ripple` | the 0.3 expanding ring |
| `pulse` | a filled disc that grows and fades |
| `burst` | eight short rays flying out |
| `ring` | two rings, one after the other |
| `none` | no animation (the cursor still presses) |

Colour: the step's `highlight`, else `style.accent`.

## 4. Watermark

```json
"style": { "watermark": { "text": "acme.com", "image": "brand/mark.svg", "position": "bottom-right", "opacity": 0.6, "size": 28 } }
```

Text, an image (SVG/PNG/JPEG/WebP ≤ 2 MB, relative to the file that names it), or both (image
first). `position`: `top-left`, `top-right`, `bottom-left`, `bottom-right` (default). `opacity`
0–1 (default 0.6). `size`: text size or image height in px at 1080p (12–200, default 28). Shown
over the whole video, cards included, above everything else. It may come from the brand file.

## 5. Overlay text

- `style.captionFont`, `style.titleFont`: font families for captions/subtitles and for the intro
  and outro cards (default `style.font`).
- `style.fonts`: `[{ "family": "Brand Sans", "file": "fonts/brand.woff2", "weight": 700? }]`: font
  files (woff2/woff/ttf/otf ≤ 5 MB, relative to the file that names them) embedded into the video,
  so any family works whether or not the machine has it installed.
- `style.captionStyle`: `dark` (default, the 0.3 pill), `light` (white pill, dark text), `accent`
  (accent-coloured pill), `outline` (no pill, white text with a dark outline) or `bar` (a full-width
  band).
- `style.captionSize`: caption text size in px at 1080p (20–80; default 36, 46 in 9:16).

## 6. Voices

- `show.voice`: per-step changes to `audio.voice` (`{ "name": "Daniel" }`, or another engine),
  for a second narrator or a different language on one line. Cached like any line.
- `showtime voices [--engine system|openai|elevenlabs] [--lang uk]`: list the voices an engine
  offers (system: the machine's voices with their language; openai: its fixed list; elevenlabs: the
  account's voices, needs the key). `--try "text" --voice <name>` synthesizes a sample to
  `.showtime/voices/` and prints its path (`--play` plays it on macOS). `--json` lists
  `{ engine, voices: [{ name, language?, id?, sample? }] }`.

## 7. Studio

The inspector gains highlight colour, spotlight style and click animation for a step; the look
panel gains caption style, caption font, click animation, sound pack and watermark text.

## 8. Contracts that change

- `Style`: `click`, `spotlightDim`, `captionStyle`, `captionFont?`, `titleFont?`, `captionSize?`,
  `fonts`, `watermark?`. `Show`: `highlight?`, `spotlight` (boolean or style), `click?`, `voice?`.
  `Audio.sounds`: boolean, pack name or object.
- `Timeline`: `clickFx: { tMs, x, y, kind, color }[]` (replaces drawing from `clicks`),
  `Spotlight.kind`, `Spotlight.color`, `fonts: { family, src, weight?, style? }[]`,
  `watermark: { text?, image?, position, opacity, size } | null`. The mixer reads the sound pack
  from the script (the renderer never needs it).
- The action hash is unchanged (everything here is presentation).

## 9. Testing

Unit: schema (each field, defaults, back-compat of `sounds: true`), click effects per step and
default, spotlight kinds and colours, watermark and font embedding (data URIs, size limits, missing
files), packs are distinct and audible, custom sound files, voice overrides change the cache key,
`say -v '?'` parsing.
Integration: a render with every new option (fonts embedded, watermark image, each click kind via
stills), `showtime voices --json` on macOS, `--try` writes a WAV, the studio edits the new fields.
