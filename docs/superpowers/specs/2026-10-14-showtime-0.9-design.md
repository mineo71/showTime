# showTime 0.9.0: design — trust, new actions, backlog fixes

Status: approved for implementation (the user took the recommended bundle: "ну давай - робимо").
Builds on [0.8.0](2026-10-14-showtime-0.8-design.md).

## 1. Integration tests in CI

The Playwright, ffmpeg and Remotion suite (`npm run test:int`, 102 tests) runs only on the
author's machine; CI and the release run unit tests and the typecheck. A regression in recording or
rendering can reach npm.

- `ci.yml` gets a second job, `integration`, on Linux: Playwright's Chromium with its system
  dependencies, ffmpeg, Remotion's browser, then `npm run test:int`. It runs on pushes to `main` and
  `feat/**`, on pull requests, and when another workflow calls it (`workflow_call`).
- `release.yml` calls `ci.yml` first; it publishes only when both jobs pass.
- Tests that need macOS (the system voice) stay skipped elsewhere, as now.

## 2. New actions

```json
{ "do": "dblclick", "target": "text=Q3 revenue" }
{ "do": "click", "target": ".row", "button": "right" }
{ "do": "click", "target": ".row:nth-child(3)", "modifiers": ["Shift"] }
{ "do": "drag", "target": "#card-7", "to": "#column-done" }
{ "do": "drag", "target": ".slider-thumb", "by": { "x": 120, "y": 0 } }
{ "do": "upload", "target": "role=button[name='Upload logo']", "files": ["assets/logo.png"] }
{ "do": "closeTab" }
```

- **`dblclick {target, modifiers?}`.** Double click; the video shows two clicks.
- **`click` gains `button`** (`left` default, `right`, `middle`) and **`modifiers`** (`Alt`,
  `Control`, `Meta`, `Shift`, `ControlOrMeta`), held during the click. `dblclick` takes `modifiers`
  too.
- **`drag {target, to | by}`.** The cursor travels to the target, presses, carries it to the centre
  of `to` (or by `{x, y}` px) and releases. Works with HTML5 drag and drop and with pointer-based
  libraries (the move is a stream of pointer events). The target is scrolled into view like any
  target; `to` is not scrolled, so both ends must be on screen together: a `to` outside the viewport
  is an error that says so. Zoom and spotlight frame both ends. While dragging, the drawn cursor
  stays pressed.
- **`upload {target, files}`.** `files` are relative to the script; a missing one is an error naming
  it. The target is what a person clicks to choose files (a button, a drop zone, a visible file
  input): the cursor clicks it and the file chooser receives the files. A hidden
  `<input type=file>` is filled directly, without the cursor. A target that opens no file chooser is
  an error that says to target the button a person clicks.
- **Tabs and popups.** A step that opens a new tab or popup (a `target=_blank` link,
  `window.open`) is followed: later steps act in the new page and the video shows it. When that page
  closes itself (an OAuth popup) or `{ "do": "closeTab" }` closes it, the previous page comes back.
  `closeTab` with only one page open is an error. Setup steps follow pages too. The address bar
  keeps `style.address`.
- **Keys on screen.** A `press` step shows its keys as keycaps (`⌘` `⇧` `K`) for 1.4 s of output; a
  click or double click with modifiers shows the modifiers plus `click`. `style.keys`: `combos`
  (default: only keys with a modifier, and modifier clicks), `all` (every press), `off`. Keycaps sit
  inside the window near its bottom edge, or near its top while a caption covers the window's bottom
  (9:16 captions and burned subtitles sit in bands outside the window, so they never meet). Modifiers are
  drawn as `⌘` (Meta), `⌃`/`Ctrl` (Control), `⌥`/`Alt` (Alt), `⇧` (Shift): the Mac symbols on macOS,
  words elsewhere; `ControlOrMeta` as the platform's own. Named keys: `Enter`, `Esc`, `⌫`, `Tab`,
  `Space`, arrows `↑ ↓ ← →`; letters upper case.
- **`press` sounds.** With `audio.sounds`, a `press` plays a key sound.
- **`record-human`** now converts double clicks, right and middle clicks, modifier clicks, file
  uploads (the recorder knows only file names: a note asks to check the paths; the click that opened
  the chooser becomes the upload's target) and new tabs or popups: actions in every page are kept
  and lined up once recording ends; going back to an older page closes the newer ones with
  `closeTab`, except a page that closed itself (detected through `window.close`, which waits a
  second so the recorder reports the page's last click).

New actions are part of the action hash like the others; takes recorded before 0.9 stay valid.

## 3. Backlog fixes

1. **Studio Record picks the network mode.** With a `replay` section, the studio's Record has a
   choice of `auto`, `live`, `record`, `replay`.
2. **`check --until` says what it does with the network:** recording without saving
   ("not saved: --until rehearses part of the script"). The JSON report carries `until` when the
   rehearsal stopped early, and the log ends with a line saying later steps were not rehearsed.
3. **`--locales` errors name `--locales`**, and an unknown code is reported before anything runs.
4. **Globs without a scheme route WebSockets too.** `**/ws` now matches `ws://host/ws`; globs that
   start with `http://`/`https://` stay HTTP-only and `ws://`/`wss://` WebSocket-only.
5. **Inspector numbers.** Freeze and Hold reject text that isn't a whole number ≥ 0 (the field turns
   red and keeps the old value) instead of removing the value.
6. **A page from an earlier studio run** gets "This page is from an earlier studio session. Reload
   it." instead of a bare "Forbidden.".
7. **A brand file created after the studio started** is picked up: the studio watches the script's
   folder and every folder above it for `showtime.config.json`.
8. **Ctrl+C stops running hooks:** their process groups are terminated, like the server's.
9. **Service workers are blocked** when the script has `app.mock` or `replay`, so a service worker
   can no longer answer requests the mocks or the replay should.
10. **The replay file's temporary name is unique per run**, so two runs never write the same `.tmp`.
11. **Locale tags with three parts** (`zh-Hant-TW`) are accepted.
12. **Studio Record and Render refuse an invalid script** with its error, instead of using the last
   good version.

## 4. Contracts that change

- `StepSchema`: `dblclick`, `drag`, `upload`, `closeTab`; `click.button?`, `click.modifiers?`.
- `StyleSchema.keys`: `'combos' | 'all' | 'off'` (default `combos`).
- `TakeEvents.drags?: Interval[]` (source ms, while the button is held).
- `Timeline.keys: { startMs; endMs; caps: string[] }[]` (source ms), `Timeline.drags: Interval[]`.
- `StepContext.dir?` (where `upload` files resolve), `StepContext.tabs?`, `StepContext.onPage?`.
- `Session.page` is the active page; `Session.tabs`.
- `trackNetwork(context)` counts requests of every page.
- `Capture.follow(page)` moves the screencast to another page.
- `CheckReport.until?`.
